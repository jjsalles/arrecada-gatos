# Projeto Gatos

## Sobre o projeto

Projeto de desenvolvimento front-end criado com o objetivo de desenvolver uma aplicação web voltada ao tema de cuidados e informações sobre gatos.

A aplicação apresenta conteúdos relacionados ao universo felino, utilizando uma interface organizada e responsiva, com foco em experiência do usuário, estruturação de páginas e aplicação de boas práticas de desenvolvimento web.

## Funcionalidades

- Apresentação de informações e conteúdos sobre gatos
- Organização de conteúdo em seções
- Interface responsiva para diferentes dispositivos
- Componentes visuais personalizados
- Interações desenvolvidas com JavaScript

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Conceitos aplicados

- Estruturação semântica de páginas HTML
- Estilização e responsividade com CSS
- Manipulação do DOM com JavaScript
- Organização de arquivos e componentes
- Desenvolvimento de interfaces web
